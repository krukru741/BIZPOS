Design a complete modern SaaS web application called **FreshMart POS**.

FreshMart POS is a grocery store management platform that helps small and medium grocery stores manage inventory, billing, daily sales, purchases, expenses, and reports.

The design should feel like a combination of:
- Shopify Admin
- Square POS
- Stripe Dashboard
- Linear
- Apple
- Notion

The UI must be minimal, elegant, modern, highly usable, and optimized for speed at the checkout counter.
